# 아홉 말 모리스 ⚪

컴퓨터와 하거나 방 코드로 친구와 실시간 대결하는 아홉 말 모리스(Nine Men's Morris, 2인). [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. `public/`(`index.html` + `logic.js` + `game.js`)과 온라인 대전용 `server.js`(`ws`)로 이루어져 있습니다.

- **판**: 큰 네모·중간 네모·작은 네모가 겹친 모양의 **점 24개**. 변 가운데 점은 안팎 네모로 이어진다. 각자 말 **아홉 개**(노랑이 먼저, 분홍이 나중)
- **1단계 놓기**: 번갈아 빈 점에 말을 하나씩 놓는다. 아홉 개를 다 놓을 때까지
- **2단계 움직이기**: 말을 다 놓은 뒤에는 말 하나를 골라 선을 따라 **이웃한 빈 점으로 한 칸** 옮긴다
- **3단계 날기**: 판 위(와 놓을 말)에 말이 **세 개**만 남으면 아무 빈 점으로나 날아갈 수 있다
- **밀**: 같은 선 위의 세 점(네모의 한 변 12개 + 안팎을 가로지르는 선 4개 = 16줄)을 내 말로 채우면 **상대 말 하나를 뺏는다**. 놓을 때도 옮길 때도 되고, 밀을 열었다가 다시 닫으면 또 뺏는다. 상대의 **밀 안에 있는 말은 못 뺏고**, 상대 말이 전부 밀 안이면 아무거나 뺏을 수 있다
- **이기는 법**: 상대 말이 **두 개**로 줄거나, 상대가 **움직일 수 없으면**(날 수 없는데 갇힘) 이긴다. 말을 놓는 단계에는 갇히지 않는다
- **무승부**: 같은 판이 세 번 나올 때(말을 다 놓은 뒤) · 말을 놓거나 뺏는 일 없이 60수가 지났을 때 · 300수를 넘겼을 때
- **간단하게 한 것**: 한 번에 두 줄을 만들어도 뺏는 말은 하나다(정식 규칙과 같음). 반복 판 세기는 "말을 둘 다 다 놓은 뒤"부터 센다
- **컴퓨터**: 쉬움은 밀을 만들 수 있으면 대체로(80%) 만들고 아니면 아무 동작이나 고른다(막지는 않는다). 보통은 **2수 앞**을 내다보는 같은 탐색이고 네 번에 한 번쯤(`NORMAL_SLIP`)은 쉬움처럼 둔다. 어려움은 **4수 앞을 내다보는 알파-베타 탐색**(말 수 차이 x100 + 밀·두 개 열린 줄·움직일 곳 수)이고 **다섯 번에 한 번쯤(`HARD_SLIP`)은 쉬움처럼 둔다**. 밀을 만드는 수·상대 밀을 막는 수를 먼저 살펴 가지치기를 돕는다. 컴퓨터 대전은 "다시 하기"마다 먼저·나중이 바뀐다
- **온라인 대전**: 빠른 대전 · 4글자 방 코드(초대 링크 `?room=코드`) · 재접속(30초) · 한 번 둘 때마다 45초(넘기면 시간패, 기권·이탈도 패배) · 한 판 더(먼저·나중 교대). 모든 동작은 `act` 하나(`{type:'place', to}` · `{type:'move', from, to}` · `{type:'remove', at}`)로 오고 서버가 같은 규칙(`public/logic.js`)으로 검사한다. 밀을 만들면 같은 사람이 이어서 `remove` 를 보내야 한다. 지금 둘 수 있는 동작(`legal`)은 차례인 쪽에만 보낸다
- 화면: 놓는 단계는 빈 점을 누르고, 움직이는 단계는 **내 말을 눌러 고른 뒤 초록 점(갈 수 있는 곳)을 누른다**. 밀을 만들면 그 줄이 붉게 빛나고 뺏을 수 있는 상대 말이 붉게 깜빡인다. 방금 둔 자리는 점선 동그라미로 보인다
- 컴퓨터를 이긴 횟수는 `morrisWins` (로비 표시용), 온라인 전적은 `morrisOnline`

규칙·컴퓨터는 `public/logic.js`(화면 없이 Node 로 시험), 화면·입력·소리·온라인은 `public/game.js`, 방·매칭은 `server.js`. 시험은 `npm test`(= `node --test`): `test/logic.test.js`(점 24개·이웃 수·밀 16줄에 점마다 두 줄, 놓기, 밀과 떼기, 안팎을 가로지르는 줄, 밀 안의 말 보호, 한 칸 움직이기, 날기, 밀 다시 닫기, 두 개로 줄어 지기, 갇혀서 지기와 날 수 있으면 안 짐, 세 번 반복, 60수 무승부, 무작위 60판에서 말 수 보존, 컴퓨터가 밀을 닫고 막고 밀 밖의 말을 뗌, 어려움이 쉬움을 이김), `test/server.test.js`(서버를 띄워 매칭 · 차례인 쪽에만 둘 동작 · 입력 검사 · 두 화면 동기화 · 밀을 만들면 떼기만 가능 · 무작위로 끝까지 · 기권 · 한 판 더 · 시간 초과 · 재접속).
